# Project 3: HOUSE RENT PREDICTION SYSTEM

**Domain Category:** 1. Machine Learning Projects  
**Level:** Undergraduate Computer Science / AI / Data Engineering  
**Pacing:** 10 Weeks Step-by-Step Student Project

## Overview
Predicts realistic monthly residential rental rates based on bedroom configurations (BHK), total square footage, city zone, furnishing status, and building floor level.

## How Students Should Use This Project
1. Start at `week_01_requirement_analysis`.
2. Open each week folder in your terminal and IDE (VS Code, PyCharm, etc.).
3. Read that week's `README.md` carefully and execute the commands step by step.
4. Complete the assigned **Student Task** before moving on to the next week.
5. Notice that each week is **cumulative**: Week $N$ contains all accumulated source code and documents from Weeks 1 through $N$.
6. Week 10 is the final, complete, deployable capstone project with automated tests, FastAPI service, and browser dashboard.

## Prerequisites
- Python 3.10, 3.11, or 3.12 installed.
- Standard web browser (Chrome, Edge, Firefox).
- Optional: Docker Desktop (for container deployment in Week 10).
